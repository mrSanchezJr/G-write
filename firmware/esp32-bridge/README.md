# Беспроводной мост Wi-Fi (ESP-32S) <-> ЧПУ контроллер Inectra MSC-3US

Проект для **PlatformIO**, превращающий модуль **ESP-32S (ESP32)** в высокоскоростной двусторонний TCP-мост (UART <-> TCP) с ультранизкой латентностью для беспроводного управления ЧПУ контроллером **Inectra MSC-3US**.

---

## 1. Схема аппаратного подключения ESP-32S к Inectra MSC-3US

### Рекомендуемая конфигурация (Hardware Serial2):
По умолчанию в прошивке включен аппаратный **UART2** ESP32:
- **RX2:** GPIO 16
- **TX2:** GPIO 17

При таком подключении USB-порт (Serial0 на COM10) остаётся полностью свободным для вывода отладочных сообщений и удобной перепрошивки кабелем без отключения контроллера.

| ESP-32S пин | Назначение | Пин на плате Inectra MSC-3US | Примечание |
| :--- | :--- | :--- | :--- |
| **GND** | Общий провод (Земля) | **GND** | **Обязательно объединить земли!** |
| **GPIO 16 (RX2)** | Приёмник UART ESP32 | **TX** контроллера Inectra | Перекрёстное подключение (RX <- TX) |
| **GPIO 17 (TX2)** | Передатчик UART ESP32 | **RX** контроллера Inectra | Перекрёстное подключение (TX -> RX) |
| **VIN (5V) / 3.3V**| Питание ESP32 | **+5V** или **+3.3V** | Питать от стабильного источника (ток пиковый до 500 мА) |

> [!IMPORTANT]
> - Линии RX и TX подключаются **крест-накрест**: `ESP32 RX (16)` -> `Inectra TX`, `ESP32 TX (17)` -> `Inectra RX`.
> - Общий провод **GND** между ESP32 и контроллером Inectra обязателен для устранения разности потенциалов.

## 2. Настройки сети и портов

Настройки задаются в файле [`include/config.h`](file:///c:/Users/Ilyha/OneDrive/Документы/displayController/include/config.h):

1. **Wi-Fi роутер:**
   ```cpp
   #define WIFI_SSID           "kyvartirad34"
   #define WIFI_PASSWORD       "pa33-3e7"
   #define WIFI_CONNECT_TIMEOUT 15000  // 15 секунд ожидания роутера
   ```
2. **Резервная точка доступа (Fallback AP):**
   Если ESP32 не может подключиться к указанному роутеру (например, станок вывезен в мастерскую или роутер выключен), контроллер автоматически поднимает собственную защищённую Wi-Fi сеть:
   - **SSID:** `Inectra-CNC-Bridge`
   - **Пароль:** `12345678`
   - **IP-адрес в режиме AP:** `192.168.4.1`
3. **TCP Сервер:**
   - **Порт:** `8088` (по умолчанию)
   - Отключен алгоритм Нагла (`setNoDelay(true)`) для мгновенной доставки пакетов и опроса статуса `?`.
4. **Скорость UART:**
   - `115200` бод (стандартная для Inectra MSC-3US). Буферы приёма: 2048 байт.

## 3. Сборка и прошивка

### Прошивка по кабелю (через COM10):
```powershell
pio run --target upload
```

### Монитор порта (отладка и получение выданного IP):
```powershell
pio device monitor -b 115200
```

### Обновление по воздуху (ArduinoOTA):
Когда модуль уже подключён к вашей Wi-Fi сети:
```powershell
pio run --target upload --upload-port <IP_АДРЕС_ESP32>
```

## 4. Управление из программы G-write на ПК

В программу **G-write** (проект `ASIS-3AX`) встроен модуль прямого подключения по TCP:
1. Запустите [ASIS-3AX.exe](file:///c:/Users/Ilyha/OneDrive/Рабочий%20стол/G-write-1.0.9%20—%20TCP/G-write/bin/Release/Publish/ASIS-3AX.exe).
2. В верхнем блоке подключения выберите переключатель **Wi-Fi (TCP)**.
3. Укажите IP-адрес модуля:
   - Если ESP32 подключён к роутеру: локальный IP (например, `192.168.1.150`).
   - Если ПК подключён напрямую к точке `Inectra-CNC-Bridge`: `192.168.4.1`.
4. Порт: `8088`.
5. Нажмите **Подключить**.
6. При успешном соединении статус перейдёт в зелёный цвет, разблокируются кнопки ручного управления, позиционирования и отправки G-кода.
