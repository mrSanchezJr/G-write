# G-write (CNC Controller Interface with Wi-Fi TCP Support)

[![.NET 8](https://img.shields.io/badge/.NET-8.0-blue.svg)](https://dotnet.microsoft.com/)
[![PlatformIO](https://img.shields.io/badge/PlatformIO-ESP32-orange.svg)](https://platformio.org/)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE.txt)

Программный комплекс для управления ЧПУ станками (под управлением контроллеров **Inectra MSC-3US**, GRBL и совместимых) по USB Serial COM-порту и по беспроводной сети **Wi-Fi (протокол TCP)** с помощью микроконтроллера **ESP-32S**.

---

## 📋 Основные возможности

- 📡 **Два режима связи**:
  - **Wi-Fi (TCP)**: прямое низколатентное сетевое подключение к ESP-32S через TCP-сокет без использования сторонних эмуляторов виртуальных COM-портов.
  - **COM-порт**: классическое проводное подключение через USB Serial (115200 бод).
- 🔄 **Горячее переключение**: переключение между COM и TCP на лету в интерфейсе с автосохранением параметров в `connection_config.json`.
- 🎮 **Управление осями**:
  - Ручные перемещения по осям X, Y, Z с выбором шага (0.1, 1, 5, 10, 50 мм) и скорости подачи.
  - Нулевание и поиск баз (Home XY, Home Z).
  - Интегрированный виртуальный сенсорный пульт Numpad.
- 📐 **Генерация траекторий**: автоматический расчет и отправка зигзагообразных траекторий обработки.
- ⚡ **Высокая производительность**:
  - Потоковый асинхронный вывод в терминал с кольцевым буфером на 300 строк (без лагов на слабых ПК).
  - Линейная асинхронная потоковая отправка G-кода с таймаутом подтверждения ответа `ok` (без переполнения стека).
  - Быстрый парсинг координат и подавление избыточных перерисовок интерфейса.
- 🎨 **Визуальный дизайнер**: интерфейс полностью совместим с визуальным дизайнером WinForms в Visual Studio.

## 🛠️ Аппаратное подключение (ESP-32S <-> Inectra MSC-3US)

Для беспроводной связи используется модуль **ESP-32S (ESP-WROOM-32)** в роли прозрачного моста между Hardware UART контроллера ЧПУ и TCP-сокетом.

| Пин ESP-32S | Пин Inectra MSC-3US | Описание |
|---|---|---|
| **GPIO 16 (RX2)** | **TX** | Прием данных от контроллера ЧПУ |
| **GPIO 17 (TX2)** | **RX** | Передача команд в контроллер ЧПУ |
| **GND** | **GND** | Общий провод «земли» (обязательно!) |
| **VIN / 5V** | **+5V** | Питание модуля (от станка или внешнего источника) |

> [!NOTE]
> Основной порт USB Serial0 микроконтроллера ESP-32S остается свободным для вывода отладочных логов и обновления прошивки.

## 📡 Прошивка микроконтроллера (PlatformIO)

Исходный код прошивки расположен в папке `firmware/esp32-bridge`.

### 1. Настройка параметров Wi-Fi
Параметры сети настраиваются в файле `firmware/esp32-bridge/include/config.h`:
```cpp
#define WIFI_STA_SSID     "Ваш_SSID"
#define WIFI_STA_PASS     "Ваш_Пароль"
#define TCP_SERVER_PORT   8088
```

### 2. Режимы работы Wi-Fi
1. **Режим станции (STA)**: модуль автоматически подключается к вашей локальной сети Wi-Fi и выводит полученный IP-адрес в монитор порта.
2. **Точка доступа (AP)**: если локальная сеть недоступна, ESP-32S создает собственную сеть:
   - **SSID**: `Inectra-CNC-Bridge`
   - **Пароль**: `12345678`
   - **IP-адрес**: `192.168.4.1`
   - **TCP порт**: `8088`

### 3. Сборка и прошивка
Установите [PlatformIO Core](https://platformio.org/) и выполните в каталоге `firmware/esp32-bridge`:
```bash
# Сборка проекта
pio run

# Загрузка прошивки в ESP-32S (например, подключен к COM10)
pio run --target upload --upload-port COM10

# Монитор последовательного порта (115200 бод)
pio device monitor -p COM10 -b 115200
```

## 💻 Сборка и запуск C# приложения (G-write)

### Требования
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- ОС Windows 7 SP1 / 10 / 11

### Сборка из командной строки
```bash
# Сборка проекта
dotnet build G-write/ASIS-3AX.csproj -c Release

# Публикация автономного релиза
dotnet publish G-write/ASIS-3AX.csproj -c Release
```
Готовые исполняемые файлы будут помещены в:
`G-write/bin/Release/net8.0-windows7.0/publish/`

### Запуск и подключение
1. Запустите `ASIS-3AX.exe`.
2. В блоке **«Подключение к контроллеру (COM / TCP Wi-Fi)»**:
   - Выберите **Wi-Fi (TCP)**: введите IP-адрес ESP32 (например `192.168.4.1` или назначенный роутером IP) и порт `8088`.
   - Или выберите **COM-порт**: нажмите кнопку «Обновить» и укажите порт контроллера.
3. Нажмите кнопку **«Подключить»**.
4. После успешного соединения статус изменится на зеленый, и станок будет готов к приему команд.

```
├── G-write/                    # Исходный код приложения на C# (.NET 8 WinForms)
│   ├── Form1.cs                # Основная логика работы и обработки команд
│   ├── Form1.Designer.cs       # Описание компонентов для WinForms Designer
│   ├── Form1.resx              # Локализованные ресурсы и свойства элементов интерфейса
│   ├── ICNCConnection.cs       # Интерфейс абстракции подключения (Serial / TCP)
│   ├── SerialCNCConnection.cs  # Реализация подключения через USB COM-порт
│   ├── TcpCNCConnection.cs     # Реализация подключения через Wi-Fi TCP
│   ├── ConnectionConfig.cs     # Конфигурация и сериализация настроек подключения
│   └── ASIS-3AX.csproj         # Файл проекта .NET 8
├── firmware/
│   └── esp32-bridge/           # Проект PlatformIO для ESP-32S
│       ├── platformio.ini      # Конфигурация платы esp32dev
│       ├── include/config.h    # Настройки Wi-Fi, пинов UART и буферов
│       └── src/main.cpp        # Реализация прозрачного двунаправленного моста
├── CHANGELOG.md                # Подробный лог изменений
├── LICENSE.txt                 # Лицензия проекта (GPL-3.0)
└── G-write.sln                 # Файл решения Visual Studio
```
