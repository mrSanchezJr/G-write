# G-write (Cross-Platform CNC Controller Interface)

[![.NET 8](https://img.shields.io/badge/.NET-8.0-blue.svg)](https://dotnet.microsoft.com/)
[![Avalonia UI](https://img.shields.io/badge/Avalonia-11.2-purple.svg)](https://avaloniaui.net/)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux-green.svg)]()
[![Controller](https://img.shields.io/badge/CNC-Inectra%20MSC--3US-orange.svg)]()

Кроссплатформенная (Windows и Linux) программа для управления 3-осевым ЧПУ контроллером **Inectra MSC-3US** (и совместимыми с GRBL) через **USB Serial (COM-порт)** и по беспроводной сети **Wi-Fi (TCP-сокет к мосту на ESP-32S)**.

Программа разработана на базе **C# (.NET 8) и Avalonia UI** в классическом монолитном стиле **Code-Behind (без усложненного ООП и многослойных абстракций)** и представляет собой точную 1:1 функциональную копию оригинальной программы `G-write`.

---

## 🚀 Основные возможности

1. **Два режима связи**:
   - **Wi-Fi (TCP)**: прямое низколатентное сетевое подключение к ESP-32S (`192.168.4.1` или локальный IP роутера, порт `8088`) без сторонних виртуальных COM-портов.
   - **COM-порт (USB Serial)**: прямое проводное подключение (115200 бод, 8N1).
   - Автоматическое сохранение выбранного режима и параметров в `connection_config.json`.
2. **Кроссплатформенность (Windows & Linux)**:
   - На Windows автоматически обнаруживаются порты `COM1`, `COM2`, `COM10`...
   - На Linux автоматически обнаруживаются устройства `/dev/ttyUSB*`, `/dev/ttyACM*` и `/dev/serial/by-id/*`.
3. **Мониторинг координат (X, Y, Z)**:
   - Опрос статуса станка по таймеру 100 мс командой `?`.
   - Быстрый разбор строки `WPos:X,Y,Z`.
   - Кэширование значений для плавной работы без мерцания и нагрузки на процессор.
4. **Ручное управление осями (Джог)**:
   - Кнопки перемещения: `▲ Y+`, `▼ Y-`, `◄ X-`, `► X+`, `▲ Z+`, `▼ Z-`.
   - Управление со стрелок клавиатуры (Left, Right, Up, Down).
   - Выбор шага: `0.1`, `1`, `5`, `10`, `50`, `100` мм.
   - Выбор скорости подачи: `10`, `20`, `50`, `100` мм/с (автоматический пересчет в `F` мм/мин).
5. **Базирование и обнуление**:
   - Поиск базы по концевикам (`$H`) с безопасным переключением и сбросом (`$X`).
   - Базирование XY (`G28 X0 Y0`) и Z (`G28 Z0`).
   - Сброс/обнуление системы координат детали (`G91 Z 0.1` -> `G91 Z -0.1` -> `G28.1 X0 Y0 Z0` -> `G10 L20 P1 X0 Y0 Z0`).
   - Быстрый возврат в точку начала сканирования ("В начало").
6. **План сканирования (Зигзаг)**:
   - Задание координат точек A (начало) и B (конец).
   - Кнопки копирования текущих координат станка в поля ввода.
   - Автоматический расчет зигзагообразной траектории, длины перемещения и времени сканирования (сек).
   - Сохранение параметров в комментариях заголовка G-кода (`; x1=... y1=...`).
7. **Работа с файлами G-кода**:
   - **Сохранить**: экспорт сгенерированного кода в файл `.gcode`.
   - **Загрузить**: открытие `.gcode` с авто-заполнением полей координат, шага, скорости и времени.
8. **Потоковое выполнение (Стриминг)**:
   - Линейная отправка кадров с ожиданием ответа `ok` и защитой от зависания (таймаут 5 секунд).
   - Индикатор прогресса и статусная строка.
   - **Пауза**: подача байта `0x82` (Feed Hold), возобновление по `~`.
   - **Аварийный СТОП**: подача байта `0x18` (Soft Reset), разблокировка по `$X`.
9. **Терминал и консоль**:
   - Ручной ввод G-кода с клавиатуры (отправка по Enter или кнопке "Отправить").
   - Безопасный ввод `$$` с временной остановкой таймера для чистого чтения EEPROM контроллера.
   - Автоматический кольцевой буфер терминала (макс. 300 строк).
10. **Сенсорная клавиатура (Numpad)**:
    - Плавающее немодальное окно с крупными цифровыми кнопками 0-9, `.`, Backspace, Стереть для работы на сенсорных экранах и промышленных планшетах.
11. **Векторное автоматическое масштабирование (Viewbox)**:
    - Контейнер `<Viewbox Stretch="Uniform">` обеспечивает автоматическую подстройку интерфейса.
    - Вы можете просто растягивать или сжимать окно за угол: все элементы, шрифты, кнопки и иконки пропорционально масштабируются в реальном времени, ничего не съезжает и не обрезается.
12. **Регулировка прозрачности**:
    - Плавный слайдер прозрачности окна от 20% до 100%.

## 💻 Запуск и компиляция

### 1. Запуск на Windows
```bash
cd "C:\Users\Ilyha\OneDrive\Рабочий стол\G-write-CrossPlatform"
dotnet run
```
Или запустите готовый исполняемый файл:
`bin\Release\net8.0\win-x64\publish\G-write.exe`

### 2. Запуск на Linux (Ubuntu, Debian, Linux Mint, Raspberry Pi OS)

#### Предварительные настройки прав доступа к Serial-порту:
Чтобы приложение имело доступ к `/dev/ttyUSB*` и `/dev/ttyACM*`, добавьте пользователя в группу `dialout`:
```bash
sudo usermod -a -G dialout $USER
```
*(После этого необходимо перезайти в систему).*

#### Запуск из исходного кода:
```bash
dotnet run
```

#### Запуск автономного бинарника:
```bash
cd bin/Release/net8.0/linux-x64/publish/
chmod +x G-write
./G-write
```

## 🛠️ Сборка автономных пакетов (Publish)

- **Для Windows (x64)**:
  ```bash
  dotnet publish -c Release -r win-x64 --self-contained false
  ```
- **Для Linux (ПК x64)**:
  ```bash
  dotnet publish -c Release -r linux-x64 --self-contained true
  ```
- **Для Linux ARM64 (Raspberry Pi 4/5, Orange Pi)**:
  ```bash
  dotnet publish -c Release -r linux-arm64 --self-contained true
  ```
