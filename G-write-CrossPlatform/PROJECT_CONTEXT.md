# Контекст проекта G-write (ASIS-3AX Cross-Platform)

> **Назначение документа:** Этот файл содержит подробное архитектурное и техническое описание проекта `G-write-CrossPlatform`. При переносе задачи в новую сессию или чат с искусственным интеллектом передайте данный файл для мгновенного восстановления полного контекста проекта без потери деталей.

---

## 1. Общие сведения о проекте

* **Название программы:** `G-write` (внутреннее кодовое имя `ASIS-3AX`).
* **Назначение:** Кроссплатформенное графическое приложение оператора для управления 3-осевым ЧПУ контроллером **Inectra MSC-3US** (и другими GRBL-совместимыми системами).
* **Стек технологий:** C#, **.NET 8.0**, **Avalonia UI 11.2.0** (Fluent Theme), `System.IO.Ports 8.0.0`.
* **Целевые платформы:** Windows 10/11 (x64), Linux (x64, включая одноплатные компьютеры Raspberry Pi / Orange Pi).
* **GitHub Репозиторий:** [`mrSanchezJr/G-write`](https://github.com/mrSanchezJr/G-write).

---

## 2. Аппаратное взаимодействие и протоколы связи

Программа поддерживает два взаимозаменяемых режима связи через модульную абстракцию интерфейса `ICNCConnection`:

1. **USB Serial COM-порт (`SerialCNCConnection.cs`):**
   * Прямое проводное подключение через виртуальный COM-порт USB.
   * Стандартная скорость обмена: **115200 бод**, 8 бит данных, 1 стоп-бит, без контроля четности.
   * Кроссплатформенная поддержка портов: `COMx` в Windows, `/dev/ttyUSB*` / `/dev/ttyACM*` в Linux.

2. **Беспроводной Wi-Fi TCP (`TcpCNCConnection.cs`):**
   * Прямое сетевое управление по TCP-сокету через аппаратный мост на базе микроконтроллера **ESP-32S (ESP-WROOM-32)**.
   * ESP-32S подключается к аппаратному UART2 контроллера Inectra (GPIO 16 RX2 <-> TX Inectra, GPIO 17 TX2 <-> RX Inectra, общая земля GND, питание 5V).
   * Порт TCP по умолчанию: **`8088`**; резервный IP точки доступа AP: **`192.168.4.1`**.
   * Сокет настроен с флагом `NoDelay = true` для минимизации задержек пакетов.

3. **Автосохранение конфигурации (`ConnectionConfig.cs`):**
   * Все параметры (последний выбранный COM-порт, IP-адрес, TCP-порт, активный режим) автоматически сериализуются в локальный файл `connection_config.json`.

## 3. Графический интерфейс и адаптивность (UI & Scaling)

1. **Векторное масштабирование (`<Viewbox Stretch="Uniform">`):**
   * Все элементы главного окна помещены в единый контейнер `<Viewbox Stretch="Uniform">`. При растягивании или сжатии окна за угол весь интерфейс пропорционально масштабируется без перекрытий, сдвигов и полос прокрутки.
   * `MinWidth="640"` и `MinHeight="400"` предотвращают чрезмерное сжатие.

2. **Безопасный авторазмер окна при старте (`AdjustInitialWindowSize`):**
   * При открытии окна (`OnOpened`) вычисляется реальная рабочая область экрана с учетом системного DPI scaling (`screen.Scaling`).
   * Если базовое разрешение окна (1440x860) превышает 88% видимой рабочей области монитора, размер окна автоматически пропорционально уменьшается, и окно центрируется. Это гарантирует наличие системных рамок для удобного перемещения и изменения размера даже на небольших мониторах оператора.

3. **Экранная клавиатура (Numpad, `NumpadWindow.axaml`):**
   * Независимое немодальное окно цифровой клавиатуры для сенсорных экранов, полностью приведенное к единому виду с `Gpellers` (ASIS-2AX-V).
   * Раскладка:
     * Строка 0: индикатор активного поля ввода.
     * Строка 1: кнопки действий `C` (очистка) и `⌫ Стереть` (Backspace).
     * Строки 2–4: цифры 1–9 сверху вниз (1, 2, 3; затем 4, 5, 6; затем 7, 8, 9).
     * Строка 5: клавиши `-`, `0`, `.`.
     * Строка 6: полноразмерная кнопка `⏎ Ввод (след. поле)`.
   * Поведение кнопки вызова в главном окне: зафиксирован неизменный текст «Экранная клавиатура» (не переключается на «Скрыть Numpad», в точности как в ASIS-2AX-V).
   * Глобальный перехват фокуса (`GotFocusEvent` с `RoutingStrategies.Bubble`) и туннельные клики (`PointerPressedEvent`) автоматически привязывают Numpad ко всем полям ввода и выпадающим спискам, отображая название активного параметра оператору.

4. **Индикатор прогресса (Progress Bar):**
   * Высота полосы прогресса передачи кадров G-кода увеличена до `Height="42"` (как в ASIS-2AX-V) для лучшей читаемости и отображения процента выполнения оператором с расстояния.

## 4. Выпадающие списки с ручным вводом (`EditableComboBox.cs`)

В отличие от стандартного закрытого списка, оператору часто требуется как выбрать готовый пресет (например, скорость 10, 20, 50 мм/с), так и ввести произвольное числовое значение с физической или экранной клавиатуры:

* **Архитектура:** `TextBox` + `Border` со значком `▼` + выпадающий `Popup` с `ListBox`.
* **Почему `Border`, а не `Button`:** В Avalonia класс `Button.OnPointerPressed` встроенно перехватывает клик мыши и помечает его `e.Handled = true`, что блокировало раскрытие списка с 1-го нажатия. Использование `Border` с прозрачным фоном устранило проблему: список распахивается **строго с 1-го клика**.
* **Защита синхронизации:** флаг `_isUpdating` предотвращает самозакрытие списка при программной подсветке выбранного пункта во время открытия меню.
* **Закрытие по клику:** клик по любому элементу списка (даже по уже выбранному) закрывает меню.
* **Поддержка Numpad:** свойство `InnerTextBox` позволяет экранной клавиатуре Numpad фокусироваться на поле списка и вводить значения.

## 5. Система версий и обновлений (Single Source of Truth)

1. **Единая точка правды:**
   Версия приложения задается **исключительно в файле `G-write.csproj`**:
   ```xml
   <Version>1.1.7</Version>
   <AssemblyVersion>1.1.7.0</AssemblyVersion>
   <FileVersion>1.1.7.0</FileVersion>
   ```

2. **Класс `AppVersion.cs`:**
   * Автоматически считывает версию через `Assembly.GetExecutingAssembly().GetName().Version`.
   * Содержит константы репозитория GitHub: `RepoOwner = "mrSanchezJr"`, `RepoName = "G-write"`.
   * Формирует строки: `DisplayString` (`"1.1.7"`) и `LabelString` (`"Ver: 1.1.7"`).

3. **Синхронизация с UI:**
   * Правый верхний угол главного окна: `label12.Text = AppVersion.LabelString;`.
   * Окно «О программе» (`AboutWindow`): динамическая строка версии.

4. **Проверка обновлений через GitHub REST API (`UpdateWindow.axaml.cs`):**
   * Запрос к `https://api.github.com/repos/mrSanchezJr/G-write/releases/latest` с обязательным заголовком `User-Agent`.
   * **Корректная обработка 404:** если на GitHub еще нет опубликованных релизов, программа сообщает оператору: *"Текущая версия: 1.1.7. На GitHub пока нет опубликованных релизов. У вас установлена актуальная сборка"* (без ложной ошибки сети).
   * **Семантическое сравнение (`Version.TryParse`):** отсекает префикс `v` (например, `v1.1.8` -> `1.1.8`) и сравнивает $remote > current$.
   * Выводит оператору changelog релиза («Что нового») и открывает страницу загрузки по кнопке.

## 6. Сборка и автономное развертывание (Self-Contained Single-File)

Программа собирается в полностью автономные исполняемые файлы со **вшитым внутри .NET 8, Avalonia и всеми зависимостями**. Конечным пользователям **не требуется устанавливать .NET**:

* **Скрипт быстрой сборки:** [`build-all.bat`](build-all.bat) (написан на чистом ASCII для исключения сбоев кодировок `cmd.exe`).
* **Профили публикации Visual Studio:**
  * `Properties/PublishProfiles/win-x64-standalone.pubxml` -> `bin/Publish/win-x64/G-write.exe` (~89 МБ, готовый к запуску Windows .exe).
  * `Properties/PublishProfiles/linux-x64-standalone.pubxml` -> `bin/Publish/linux-x64/G-write` (автономный бинарник Linux).
* **Командная строка публикации:**
  ```powershell
  dotnet publish G-write.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o bin\Publish\win-x64
  ```

## 7. Логика управления ЧПУ и терминал

* **Генерация траектории (`gen()`):** построение растрового плана сканирования (зигзаг) по точкам A (X, Y) и B (X, Y) с учетом заданного шага и скорости подачи (`G01 F...`).
* **Потоковый терминал (`AppendLog`):** вывод логов с кольцевым буфером на 300 строк (`MaxTerminalLines = 300`) для предотвращения утечек памяти при длительных многочасовых циклах сканирования.
* **Фильтрация ответов:** автоматическое подавление мусорных ответов `ok`, поступающих на служебные запросы координат (`?`), чтобы они не засоряли окно терминала.
* **Кнопка СТОП / РАЗБЛОК (`button10`):**
  * В нормальном режиме: экстренный останов (байт `!` / `0x85`), переход кнопки в состояние **`РАЗБЛОК.`**.
  * В заблокированном режиме: отправка команды разблокировки контроллера `$X\n` и возврат кнопки в состояние **`СТОП`**.
* **Кнопка ПАУЗА / ПРОДОЛЖИТЬ (`button11`):**
  * Пауза: байт `0x82` (GRBL Feed Hold), надпись меняется на «Продолжить», иконка меняется на Play.
  * Возобновление: символ `~` (GRBL Cycle Start), надпись меняется на «Пауза», иконка меняется на Pause.
* **Поиск нуля (`button15`):** аппаратное базирование по концевикам (`$H`).
* **Обнуление осей (`button14`):** макрос `G10 L20 P1 X0 Y0 Z0`.

## 8. Журнал изменений (Changelog проекта)

* **v1.1.7 (Cross-Platform Avalonia):**
  * Полный перенос функционала с WinForms на Avalonia UI (.NET 8) для Windows и Linux.
  * Внедрение векторного контейнера `Viewbox` для адаптивного масштабирования интерфейса.
  * Реализация выпадающих списков с ручным вводом `EditableComboBox` с мгновенным откликом по первому клику.
  * Добавлена система авторазмера окна под рабочую область экрана с учетом DPI scaling (`AdjustInitialWindowSize`).
  * Реализована единая система версий через `G-write.csproj` и `AppVersion.cs`.
  * Интегрирована проверка обновлений через GitHub REST API `mrSanchezJr/G-write`.
  * Настроена автономная сборка (Self-Contained Single-File) под Windows x64 и Linux x64 с профилями публикации.
  * **Синхронизация компоновки кнопок сканирования с ASIS-2AX-V:** кнопки «Генерировать», «В начало», «Отправить», «Пауза/Продолжить» выстроены вертикально в один ряд (строки 0–3, колонка 0), в точности повторяя эргономику и расположение из `Gpellers` (ASIS-2AX-V).
  * **Унификация экранной клавиатуры (Numpad) с ASIS-2AX-V:** единый стиль кнопок действий (`C`, `⌫ Стереть` сверху, `⏎ Ввод` снизу), цифры 1–9 сверху вниз.
  * **Поведение кнопки вызова клавиатуры:** зафиксирован постоянный статический текст кнопки («Экранная клавиатура») без изменения при переключении видимости окна, аналогично ASIS-2AX-V.
  * **Расширение полосы прогресса:** высота полосы выполнения G-кода (`progressBar1`) увеличена до `Height="42"`, полностью повторяя стиль ASIS-2AX-V.
  * **Унификация терминала и цветовой гаммы с ASIS-2AX-V:** аварийная кнопка «СТОП / РАЗБЛОК» переведена на фирменные контрастные цвета (`#D9534F` красный / `#F57C00` янтарный) с динамическим переключением в коде; кнопке сброса координат (`button14`) задан акцент `#FFF0F0` / `#C00000`; кнопке поиска нуля (`button15`) задан акцент `#DAE8FC` / `#0055AA`; терминал переведен на чистый белый фон с черным текстом (`TextBox.terminalBox`) с полным отключением эффектов изменения при наведении (`:pointerover`) и фокусе.
  * **Окно поверх всех окон:** главное окно переведено в режим закрепления поверх других окон (`Topmost="True"`) для непрерывного контроля за процессом 3-осевой обработки.
  * **Оптимизация и увеличение шрифтов:** для улучшенной читаемости интерфейса оператора базовый размер шрифта окна повышен до 13pt (`FontSize="13"`), заголовки функциональных блоков увеличены с 13pt до 14.5pt, кнопки действий — с 12pt до 13pt, текст терминала ЧПУ — с 11.5pt до 12.5pt, а кнопки экранной клавиатуры (Numpad) — с 16pt до 17.5pt (цифры) и до 13.5–14pt (действия).
