Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования (SemVer)](https://semver.org/lang/ru/).

## [1.1.0-TCP] — 2026-10-27

### 🚀 Добавлено (Added)
- **Управление станком по Wi-Fi (TCP)**:
  - Прямое сетевое управление ЧПУ контроллером Inectra MSC-3US через TCP сокет без необходимости сторонних виртуальных COM-портов.
  - Поддержка быстрого переключения между режимами `COM-порт` (USB Serial) и `Wi-Fi (TCP)`.
- **Прошивка аппаратного моста ESP-32S** (`firmware/esp32-bridge`):
  - Высокоскоростной прозрачный двунаправленный мост Hardware UART2 (GPIO 16 RX2, GPIO 17 TX2) <-> TCP Server (порт `8088`).
  - Минимальная задержка передачи пакетов (`WiFiServer.setNoDelay(true)`, аппаратный буфер 2048 байт).
  - Два режима работы Wi-Fi:
    - **Режим станции (STA)**: подключение к локальной сети Wi-Fi.
    - **Резервный режим точки доступа (AP)**: при недоступности сети поднимается сеть `Inectra-CNC-Bridge` (IP `192.168.4.1`, порт `8088`).
- **Модульная архитектура соединений**:
  - Интерфейс `ICNCConnection`: абстракция отправки, приема и статуса соединения.
  - `SerialCNCConnection`: реализация для прямого USB COM-порта на базе `System.IO.Ports.SerialPort`.
  - `TcpCNCConnection`: реализация для Wi-Fi TCP на базе `System.Net.Sockets.TcpClient` с асинхронным чтением.
- **Сохранение конфигурации**:
  - Класс `ConnectionConfig` и файл `connection_config.json` для автоматического сохранения последнего IP, порта, выбранного режима и имени COM-порта.
- **Поддержка Visual Studio WinForms Designer**:
  - Элементы интерфейса соединения (`rbSerial`, `rbTcp`, `lblConnStatus`, `txtTcpIp`, `txtTcpPort`, `lblTcpIp`, `lblTcpPort`) интегрированы в `Form1.Designer.cs` и `Form1.resx`. Теперь панель подключения визуально редактируется в дизайнере Visual Studio.

### ⚡ Оптимизировано (Changed / Performance)
- **Устранение зависаний терминала**:
  - Конкатенация строк `box.Text += ...` заменена на потоковый метод `box.AppendText(...)` с реализацией кольцевого буфера на 300 строк (`MaxTerminalLines = 300`).
  - Исключены просадки FPS и многосекундные фризы интерфейса на слабых ПК при интенсивном выводе ответов контроллера.
- **Устранение риска переполнения стека (StackOverflowException)**:
  - Метод отправки G-кода переведен с глубокой рекурсии `SendDataAndWaitForResponse` на плоский асинхронный цикл `StreamGCodeAsync` с таймаутом подтверждения ответа `ok` (5 секунд).
- **Оптимизация парсинга и вывода координат**:
  - Тяжелый регулярный парсер `Regex.Match` заменен на быстрый поиск подстрок `IndexOf` / `Substring`.
  - Добавлено кэширование последних выведенных координат (`lastSx`, `lastSy`, `lastSz`), предотвращающее до 90% избыточных перерисовок меток `Label`.
- **Надежность работы с ресурсами**:
  - `timer1.Dispose()` заменен на `timer1.Stop()`, что предотвратило возникновение `ObjectDisposedException` при повторном пуске.
  - Файловые потоки чтения и записи обернуты в блоки `using` (`FileStream`, `StreamReader`, `StreamWriter`) для гарантированного своевременного освобождения файловых дескрипторов.
- **Очистка и форматирование кода**:
  - Устранены дублирующиеся пустые строки в `Form1.cs` (объем сокращен с 2912 до 1380 строк).
  - Удален неиспользуемый закомментированный код.
  - Актуальные измененные блоки снабжены наглядными комментариями в формате `// БЫЛО:` / `// СТАЛО:`.

### 🗑️ Удалено (Removed)
- Зависимость от устаревшего проекта Visual Studio Installer `Setup1.vdproj`.
- Избыточные неиспользуемые переменные и ручные программные вызовы инициализации контролов.
